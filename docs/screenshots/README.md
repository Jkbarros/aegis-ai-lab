## Como gerar

1. `streamlit run app.py`
2. Execute uma campanha `hardened` para dados reais (ou use demo do dashboard).
3. Windows: `Win + Shift + S` ou ferramenta de captura.
4. Referencie no README: `docs/screenshots/dashboard-overview.png`
